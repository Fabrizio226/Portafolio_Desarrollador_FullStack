## Desarrollo local

Abre `index.html` en el navegador o inicia un servidor estático desde la raíz del repositorio.

## Publicar con GitHub Pages

1. Sube los cambios a la rama `main`.
2. En GitHub, abre **Settings > Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/(root)`, y guarda.
5. Espera a que termine la publicación y verifica el enlace del sitio.
